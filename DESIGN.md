# Quillmark design: Lente

Quillmark is a self-hosted tool for checking writing signals, not establishing authorship. Keep the approved Firma wordmark and purple; do not carry forward the original card grid, square controls or editorial serif.

- **Detector:** four source modes in one tab control; one input working surface; one action to analyse. The lens illustration references inspection, not a mascot or certification mark.
- **Report:** score first, analysed passage next, individual engine votes below. Keep the distinction between evidence and authorship visible, including at mobile sizes.
- **Coach and API:** the same tool shell. Present findings and operations as lists with spacing and separators rather than cards. Secondary actions have less visual weight than the action that advances the task.
- **Type:** sans across product surfaces, compact hard-working type for controls, bold display type for page starts, and monospaced text only for technical content.
- **Color and motion:** saturated purple for the detector lead and actions, quieter violet surfaces elsewhere. Keep keyboard focus visible and honor reduced motion.

Method reference: Impeccable by Paul Bakaus, especially New visual work, Typeset and Distill. This is a Quillmark redesign guided by Impeccable, not a design authored or endorsed by Paul Bakaus.

## Editorial artwork
Two generated, locally served WebP illustrations give each task its own moment: an editor inspecting punctuation on the detector, and two editors comparing a draft on the coach. The report and API use quieter line drawings so evidence and endpoints remain the focus. Artwork does not convey any required instructions or state. Impeccable's Polish guide informed the integration and visual verification.

## Reading edition
The detector and coach write directly on the page, with typographic tabs and editor rules. The report leaves its score and excerpt open instead of boxing them. API grouping is by headings and rules rather than tile surfaces. The queue dialog uses a short status line and clear cancellation, as a centered dialog on desktop and a bottom sheet on phones. Preserve intentional reading hierarchy and the existing artwork.

## Home reading atlas
An anchor leads directly to the detector; the reading guide below alternates illustrated plates and explanations of scoring. Each plate uses half of the same local, lazy-loaded WebP, drawn in the established Lente print style. The engine index remains fully accessible without scripting.

## Violet palette
Only violet, black and white, including printed art. A single rendering filter maps local illustrations to a violet ink ramp without duplicating files or altering the originals. Score bands use violet tones; numeric ticks, a position marker and written verdicts remain mandatory. Warnings retain an icon and clear language rather than adding a second hue.
## Document revision
The Style coach imports local PDF (selectable text, first 50 pages), DOCX, TXT, and Markdown files up to 10 MB through the established extractor. Edits are user-directed. Comparison uses the original draft, not the last revision, and TXT export never modifies the uploaded file or preserves document formatting.
