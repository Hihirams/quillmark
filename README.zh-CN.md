# Quillmark

[English](README.md) · [Español](README.es.md)

Quillmark 是由 Hiram G. 独立维护的自托管写作分析工具。可以粘贴文本、打开文档、检查公开网页，也可以使用风格建议工具。检测信号不能证明作者身份。

请参见[当前安装说明](README.md#quick-start)、[模型说明](docs/MODELS.md)和[鸣谢与来源](CREDITS.md)。原有检测器及其评测由 SlopTotal 项目开发；继承的研究结果和限制见[评测报告](tests/eval/slopbench/FINDINGS.md)。
