# Quillmark

[English](README.md) · [Español](README.es.md)

Quillmark — приложение для анализа текста и стиля на своём сервере. Независимую редакцию поддерживает Hiram G. Можно вставить текст, открыть документ или указать адрес общедоступной страницы. Сигналы детектора не доказывают авторство.

См. [инструкции по установке](README.md#quick-start), [сведения о моделях](docs/MODELS.md) и [авторство исходного проекта](CREDITS.md). Детектор и исходная оценка разработаны проектом SlopTotal; результаты и ограничения описаны в [отчёте об оценке](tests/eval/slopbench/FINDINGS.md).
